# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), with the section
names the ScalarDB family uses (Enhancements, Improvements, Bug fixes) instead of Keep a Changelog's
types. It is generated by [changie](https://changie.dev) from the files in `.changes/`; changes not
yet released are in `.changes/unreleased/`.
