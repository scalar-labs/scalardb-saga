## [v3.20.1] - 2026-11-26

### Bug fixes

- A HEAD request to a GET route other than `/health` now returns the GET's status and content type, without a body, and needs the same credential and role; it used to get 405. ([#239](https://github.com/scalar-labs/scalardb-saga/pull/239))
- The ScalarDB Saga Server container image is now based on Eclipse Temurin 25.0.5_8, whose trust store no longer includes the emSign root CA that issued the compromised eMudhra intermediate CAs, so certificates issued through those intermediates are no longer trusted (CVE-2026-91403, CVE-2026-114820). ([#231](https://github.com/scalar-labs/scalardb-saga/pull/231))
